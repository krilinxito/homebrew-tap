# StudyHomie for Homebrew

```sh
brew install krilinxito/tap/studyhomie
```

Works on macOS and Linux (Intel and ARM). Update with `brew upgrade studyhomie`. The formula is updated automatically on every [StudyHomie release](https://github.com/krilinxito/studyhomie/releases) by `packaging/render.mjs` in the main repo; do not edit it by hand.
